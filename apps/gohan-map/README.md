# ごはんマップ（梶原さん専用）

行ったお店を自分だけの地図に残して、Googleの口コミ文は Claude に「いつもの書き方」で書いてもらうアプリ。
お昼に迷ったら「お昼どこ行こ？」と聞けば、自分の記録からおすすめしてくれる。

## できること

| 画面 | 中身 |
|---|---|
| マップ | 行った店がピンで出る。**推しの店は赤いハート**、それ以外は評価で色分け（ジャンルの1文字入り）。店名・ジャンル・メモで検索、「推し」「★4以上」「最近」「ジャンル」で絞り込み |
| ＋（記録） | Googleマップの共有リンクを貼る→店名と場所が自動で入る。評価・推し・写真・雰囲気・店員の印象・ひとことを入れて「Claude に俺っぽく書いてもらう」。気に入らなければ「もっと短く」などで書き直し。コピー→「Googleマップで投稿」で貼るだけ |
| お昼相談 | 「がっつり食べたい」「近くで推しの店」などに、記録＋メモ（駐車場・店員など）を見て2〜3軒おすすめ。押すとマップでその店が開く |
| 推し | ハートの店だけのマップ |
| 設定 | Googleテイクアウトの口コミ（Reviews.json）をまとめて取り込み |

「俺っぽさ」は、**今まで書いたGoogleの口コミ**をお手本にして真似します。最初にテイクアウトで取り込むのがおすすめ（348件ぜんぶマップにも入ります）。

## 置き方（最初の1回だけ・10分くらい）

1. **Apps Script を作る**
   [script.google.com](https://script.google.com) →「新しいプロジェクト」→ 名前を「ごはんマップ」にする。
2. **ファイルを3つ貼る**
   - `コード.gs` の中身を全部消して、このフォルダの `Code.gs` を貼る
   - 左の「＋」→「HTML」→ 名前を `index` にして、`index.html` を貼る
   - 「プロジェクトの設定」→「"appsscript.json" マニフェスト ファイルをエディタで表示する」にチェック → `appsscript.json` を貼る
3. **Claude の API キーを入れる**（**今は保留中なので飛ばしてOK**）
   「プロジェクトの設定」→ 一番下「スクリプト プロパティ」→「プロパティを追加」
   - プロパティ：`ANTHROPIC_API_KEY`
   - 値：Claude の API キー（[console.anthropic.com](https://console.anthropic.com) の API Keys で作る）
4. **一度だけ動かして許可する**
   エディタ上で関数 `setupCheck` を選んで「実行」→ Googleの許可画面で「許可」。
   データ用スプレッドシート「ごはんマップ（データ）」とドライブの「ごはんマップ写真」フォルダが自動でできます。
5. **公開する**
   「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**（＝梶原さん以外は開けない）
   出てきた URL をコピー。
6. **ポータルにつなぐ**
   ポータルの `index.html` の「ごはんマップ」の `url: ""` に、その URL を貼る（または Claude に「このURL入れて」と頼む）。
   URL を入れるまでは、ポータルのタイルを押すと「準備中」と出ます。

## 過去の口コミを取り込む（おすすめ）

1. [takeout.google.com](https://takeout.google.com) →「選択をすべて解除」→「マップ（マイプレイス）」だけチェック → エクスポート
2. 届いた zip を開くと `Reviews.json`（または「クチコミ.json」）がある
3. ごはんマップの「設定」→「Reviews.json を選ぶ」
   - 全部の口コミがマップに入る（★5は推しハート）
   - 口コミ文が Claude のお手本になる
   - 同じ店は二重に入りません

## メモ

- 写真は端末で小さくしてからドライブの「ごはんマップ写真」に保存します。Googleマップへの写真投稿は、投稿画面で写真を選んでください。
- 現在地は、iPhone だとアプリの仕組み上取れないことがあります。そのときは「エリアを入れる」で「天満」「会社」などを入れればOK。
- 使う Claude は **Haiku**（一番安い）。口コミ作成も相談も1回1円しないくらい（月30回書いても数十円）。
  文章の「俺っぽさ」が物足りなければ、`Code.gs` の一番上の `MODEL` を `'claude-sonnet-5-5'`（1回5〜10円）や `'claude-opus-5-5'`（1回10〜20円・一番うまい）に変えて、デプロイを「新しいバージョン」で更新してください。
- データはスプレッドシートなので、直接直してもアプリに反映されます。
